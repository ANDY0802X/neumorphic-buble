# 🫧 Liquid Neumorphism Bubble UI ELEMENT

A modern, interactive liquid neumorphic bubble animation built with **HTML5 Canvas** and **Vanilla JavaScript**. It features fluid physics simulation, interactive mouse cursor forces, and smooth neumorphic light-and-shadow rendering.

---

## ✨ Features

- 💧 **Interactive Liquid Physics**: Fluid bubble membrane simulation that reacts smoothly to cursor drag and movement.
- 🎨 **Sleek Neumorphic Aesthetics**: Soft highlights and deep drop-shadows tailored for a dark, minimalist UI aesthetic.
- ⚡ **Zero External Dependencies**: Pure vanilla JavaScript and CSS — lightweight, fast, and dependency-free.
- 📱 **Responsive Design**: Automatically resizes and scales dynamically with the browser window.
- 🔤 **Modern Typography**: Integrated with Google Fonts (*Inter*).

## 💻 Getting Started Locally

No build steps or package managers required!

### Option 1: Direct in Browser
Simply clone the repository and open `index.html` in any modern web browser.

```bash
git clone https://github.com/ANDY0802X/neumorphic-buble.git
cd neumorphic-buble
```

### Option 2: Using a Local Server
If using VS Code, right-click `index.html` and select **"Open with Live Server"**, or run:

```bash
# Using npx serve
npx serve .

# Using Python
python -m http.server 3000
```
